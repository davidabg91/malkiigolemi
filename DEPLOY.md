# Пускане на сайта онлайн (Vercel)

Сайтът се хоства във **Vercel**. Базата данни е в **Turso**, а снимките на продуктите във **Vercel Blob**.
Всичко се настройва от сайта на Vercel, без команди на компютъра. Отнема около 15 минути.

След като е настроено, всяка промяна, която влезе в `main` в GitHub, се качва онлайн сама.

---

## 1. Създай проекта във Vercel

1. Отиди на <https://vercel.com> и натисни **Sign Up** (или **Log In**) → **Continue with GitHub**.
2. Натисни **Add New… → Project**.
3. Намери репото **malkiigolemi** и натисни **Import**.
   Ако не се вижда, натисни **Adjust GitHub App Permissions** и разреши достъп до него.
4. Отвори **Environment Variables** и добави тези три настройки:

   | Name | Value |
   |---|---|
   | `SESSION_SECRET` | дълъг случаен текст, поне 40 знака (виж по-долу) |
   | `ADMIN_EMAIL` | имейлът, с който ще влизаш в админ панела |
   | `ADMIN_PASSWORD` | паролата за админ панела (поне 8 знака) |

   Случаен `SESSION_SECRET` получаваш с тази команда в терминал, в папката на проекта:

   ```
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```

5. Натисни **Deploy**.

> **Първото пускане ще се провали с грешка „No database configured“.** Това е нормално:
> базата се добавя в следващата стъпка, след като проектът вече съществува.

## 2. Свържи базата данни (Turso)

1. В проекта отвори раздела **Storage** → **Create Database**.
2. Избери **Turso Cloud** → **Continue**. Приеми условията и избери безплатния план.
3. За регион избери най-близкия до България (например **Frankfurt**).
4. Свържи базата с проекта за всички среди (Production, Preview, Development).

Vercel сам добавя настройките `TURSO_DATABASE_URL` и `TURSO_AUTH_TOKEN`. Сайтът ги чете директно.
Ако при свързването си задал друг префикс и имената са различни, добави ръчно
`DATABASE_URL` и `DATABASE_AUTH_TOKEN` със същите стойности.

## 3. Свържи хранилище за снимки (Vercel Blob)

1. Отново в **Storage** → **Create Database** → **Blob** → **Continue**.
2. Дай име (например `snimki`) и го свържи с проекта.

## 4. Пусни отново

1. Отвори раздела **Deployments**.
2. При последното пускане натисни **⋯ → Redeploy**.

По време на пускането сайтът сам:
- създава таблиците в базата;
- зарежда примерния каталог (93 продукта), **само ако базата е празна**;
- създава админ акаунта от `ADMIN_EMAIL` и `ADMIN_PASSWORD`.

Когато свърши, натисни **Visit**. Админ панелът е на `/admin`.

## 5. След пускането

- **Снимките от компютъра не се качват автоматично.** Ако си качвал снимки локално, качи ги отново
  от админ панела (Продукти → редакция → Снимка на продукта).
- **Смяна на админ паролата:** промени `ADMIN_PASSWORD` в Settings → Environment Variables и направи Redeploy.
- **Собствен домейн:** Settings → Domains → Add.
- **Тестови линкове:** всеки pull request получава отделен адрес за преглед.
  Внимание: той ползва **същата база** като истинския сайт, така че тестовите поръчки се виждат и там.

## Какво да знаеш

- Безплатният план на Vercel (Hobby) е за **некомерсиални** сайтове. За показване на клиента е достатъчен.
  Когато магазинът започне да продава реално, премини на **Pro** (около 20 $ на месец).
- Снимките на продуктите са до **3 MB** (ограничение на Vercel за размер на заявката).
- GitHub Pages в настройките на репото не е нужен за този сайт. Можеш да го изключиш от
  GitHub → Settings → Pages → Source: **None**.
